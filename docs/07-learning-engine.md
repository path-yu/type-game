# 学习引擎：从「打对加分」到记忆调度

> 这一轮把两个有实证支持的东西接了进来：FSRS 间隔重复、先测后学。
> 前者换掉了原来那张固定阶梯，后者补上了打字练习里缺失的回忆负荷。

## 1. 原来的问题

掌握度是一套经验规则：

```
打对第一次 +30，之后 +15 / +6；打错 -8
复习间隔走固定阶梯 [1, 3, 7, 16, 35, 75] 天
```

两个毛病：

- **阶梯不看词**。`born` 和 `antidisestablishmentarianism` 打对两次，都排到 7 天后。
- **打字几乎没有回忆负荷**。整篇文章是照着英文打的，视觉线索太强 —— 眼睛看得见答案，脑子不用提取。打过十遍的词，换个场景照样认不出。

## 2. FSRS-4.5：每个词有自己的记忆曲线

FSRS 把记忆拆成三个量：

| 量 | 含义 | 范围 |
|---|---|---|
| **Difficulty** | 这个词本身有多难记 | 1–10 |
| **Stability** | 保持率降到 90% 需要多久（天） | 0.1–∞ |
| **Retrievability** | 此刻还记得住的概率 | 0–1 |

遗忘曲线是幂律（不是指数）：

```
R(t, S) = (1 + 19/81 · t / S)^(-0.5)
```

`t = S` 时正好 `R = 0.9` —— 所以「稳定度」本身就是「90% 保持率下的间隔天数」。
排期就是反解这个式子：`I(S) = S / (19/81) · (0.9^(-2) - 1) = S`。

三条增长规律来自实测记忆数据：

1. 材料越难（D 越大），稳定度涨得越慢
2. 稳定度越高，再涨越难
3. **复习时越接近遗忘，涨得越多** —— 这就是「必要难度」的数学形式

实现见 `src/lib/fsrs.ts`，权重用 FSRS-4.5 公开默认值（17 个参数）。
没在个人数据上重训：单机应用收不到足够的复习日志，训练反而会过拟合。

### 踩到的坑

第一版用了 FSRS-5 草稿里的指数难度式 `D0 = w4 − e^(w5(G−1)) + 1`。
在 G≥3 时它会被 clamp 到 1（最简单档），增长率直接拉满：

```
连续答对间隔  4 → 23 → 109 → 437 → 1527 天
```

五次复习排到四年后。改成 4.5 的线性式 `D0 = w4 − (G−3)·w5` 之后：

```
连续答对间隔  4 → 15 → 49 → 146 → 393 天
```

### 等级怎么定

打字结果映射成 FSRS 的四档评分：

| 情形 | Grade | 效果 |
|---|---|---|
| 一次没错，且是首次遇到 | Easy (4) | 初始稳定度 13.8 天 |
| 一次没错 | Good (3) | 初始稳定度 3.7 天 |
| 错了，但对的次数更多 | Hard (2) | 增长打 2.88 折 |
| 错得比对得多 | Again (1) | 稳定度打回，当天回炉 |

夜巡答对算 Good，答错算 Again。查词（点开看释义）算「承认不认识」：掌握度打回 25，
排进当晚队列，但**不记 reps** —— 只是看了一眼，不算作答。

### 夜巡队列的排序也改了

原来是「掌握度 + 逾期天数」升序，等于**逾期越久越靠后**，顺序是反的。
现在按排到期的词的实际保持率排序，越快忘的越先复习。

## 3. 先测后学：给打字补上回忆

打完卡的第二件事是 `PreTeach` 组件：进正文前，把本篇的生词先考一遍。

```
开打之前 · 先认一认                    1 / 6
              n. 装载, 装填
                l _ _ _ _ _
        [ 打出这个单词，回车确认 ]
```

只给中文和首字母，要你回忆出英文。答错就亮答案，然后继续。

为什么值得先考一遍：**pretesting effect**。即使先测时全错，后续学习同一批材料的记忆效果
也比直接学要好 —— 因为先测让大脑「定位了知识的缺口」，后续输入才有落点。

三条实现约束：

1. **只考词库里有中文释义的词**。`resolute` 这类不在 7200 频词表里的词，给不出中文就等于给不出题目。
2. **释义里的括号注释要摘掉**。`v. 热爱（love 的过去分词）` 等于把答案写在题面上。
3. **至少两个词才弹**。一个词的预习卡是打扰。

开关在「设置 → 学习 → 开打前预习生词」，默认开。

## 4. 老档迁移

`s` 字段从「0–5 的阶梯档位」变成「稳定度天数」。不迁移的话，老用户的词稳定度都是个位数，
会被当成快忘光的词，一夜之间全涌进夜巡。

`migrateMastery()` 在 `load()` 时把它们按旧阶梯换算成天数（`1/3/7/16/35/75`），
难度给中位值 5，`last` 用 `due - interval` 反推。

## 5. 测试

| 脚本 | 内容 |
|---|---|
| `test-fsrs.mjs` | 14 项：遗忘曲线在 t=S 时等于 0.9、连续答对间隔递增、忘记后缩回、难度落界、越接近遗忘涨得越多 |
| `test-pretest.mjs` | 12 项：弹出、进度、中文释义（不含括号注释）、只露首字母、答对/答错反馈、跳过回正文、跳过之后还能正常打字 |

预习卡会盖住打字区，所以 e2e / 每日卷轴 / 体检报告这三个测试在初始化时把 `pretest` 关掉，
预习行为由 `test-pretest.mjs` 单独覆盖。

## 6. 词间干扰：别把 affect 和 effect 排在一起

间隔重复系统里被低估的一个问题。同一批复习里如果同时出现 affect / effect，
两个词会互相干扰（interference），最后两个都记不牢 —— 而且用户会误以为「我都背过了」。

### 判据只有形近

`src/lib/confuse.ts` 用 **Damerau-Levenshtein 距离**：

- 普通编辑距离把 quiet ↔ quite 算成 2（最后两个字母换了位置）
- Damerau 把相邻换位算作 1 步 —— 这正是最典型的拼写失误

阈值收紧过一轮：

| 规则 | 理由 |
|---|---|
| 长度 ≤ 3 不算 | cat / car 满屏都是，错开反而凑不满队列 |
| 长度差 > 1 不算 | 那是两个不同的词，不是「看串了」 |
| 距离 1 → 算 | affect/effect、adapt/adopt |
| 距离 2 且 ≥6 字母 → 算 | through/though |
| 距离 2 且 < 6 字母 → 不算 | have/make 会被算进来 |

第一版没收紧时，7200 词表里能凑出 **42774 对**形近词（每词 6 个「对手」），
错开之后队列根本排不满。收紧到 8714 对（每词 2.6 个）才合理。

### 两处应用

1. **队列错开**：`dueWords()` 和夜巡的 `buildQueue()` 都过一遍 `spreadConfusable()` ——
   按优先级往下挑，遇到与已选词形近的先放一边，凑不满再回填。
2. **答错提示**：夜巡答错时，从「学过的词」里找出形近的对手，

```
        effect
   ⚠ 易混：affect / effort —— 看清再打
        n. 结果, 影响, 效果, 印象
```

这比单纯显示正确答案有用：用户需要知道错在哪里 —— 是拼错了，还是把两个词搞混了。

## 7. 还能往哪走

- **按遗忘曲线生成复习节奏**：现在夜巡是「一批 12 个到期词」，可以改成按 R 值动态分组。
- **义近干扰**：big / large 这类同义词也会互相干扰，但没有可靠的自动判据，硬做只会误伤。
- **产出性练习**：预习卡还是「中译英」，再往上一步是「给语境造句」，那才是真正的产出。

# 《TypeWake / 词醒》游戏设计文档（GDD）

> 一句话：**在一个文字沉睡的城市里，你是记述者。打字 = 唤醒文字。你打下的每一个词，都会变成你真正拥有的词。**
>
> 版本 v0.1 · 设计目标：一个"能让人连打 40 分钟还想再打一篇"的英文打字 + 词汇习得游戏。

---

## 0. 一页纸概览

| 项目 | 内容 |
|---|---|
| 类型 | 打字竞速（Typing Racer）+ 词汇收集 + 分级阅读 |
| 平台 | Web 优先（桌面为主，移动端可玩），PWA 可离线 |
| 单局时长 | 60–150 秒（一条"卷轴"） |
| 单次会话 | 8–15 分钟（3–5 条卷轴 + 1 次复习） |
| 内容量 | 1200+ 条分级文本（7 个难度档），核心词表 5000+，可扩展至 2 万 |
| 目标用户 | ① 中文母语、想提升英文的成年人（主线）② 想练打字速度的人（副线） |
| 核心差异 | 市面打字游戏只练手速，背单词 App 只练记忆。本作把**打字动作本身**变成词汇的主动回忆，并让"词汇量增长"成为游戏唯一的进度货币 |

### 三句话讲清玩法

1. **打字**：屏幕上出现一段英文，逐字符敲，错了不惩罚位移、只记账；连对越久，画面越亮、声音越厚。
2. **收集**：遇到不认识的词，点一下 → 出卡片（音标 / 中文 / 例句）→ 点喇叭听发音 → 收进"藏书阁"。
3. **推进**：每条卷轴按你的**生词率**推荐，永远只比你现在难一点点。城市随你点亮，7 个城区对应 A1 → C1。

### 核心循环（Core Loop）

```
         ┌──────────────────────────────────────────────┐
         │                                              │
   选卷轴（i+1 推荐）→ 打字（连击/幽灵竞速）→ 结算（WPM·准确率·新词）│
         │                                              │
         └──── 新词入册 ← 查词（点击/收藏） ←──────────────┘
                     ↓
              夜巡复习（看中文打英文 / 听音写词）→ 掌握度↑ → 解锁更难卷轴
```

**关键设计判断**：把"复习"做成**打字**，而不是选择题。因为在键盘上拼出一个词，是比"认得"强得多的记忆编码（production > recognition）。这一条决定了整个产品的骨架——学习机制和玩法机制是同一件事，而不是两张皮。

## 1. 世界观与情绪基调

**设定**：一座叫"词醒之城"的城市，所有文字在夜里沉入黑暗。记述者（玩家）用手敲击，把词一个个敲醒；醒来的词会在城中亮起一盏灯。城市不是装饰，它是你词汇量的可视化。

**为什么需要世界观**：打字游戏天然枯燥，靠"分数"驱动留存很差。给动作一个隐喻（敲醒 / 点亮），可以让每一次击键都有叙事意义，并给长线目标一个可看的形状——**玩家看到的不是进度条，是自己点亮的城市**。

**情绪曲线**（一条卷轴内）：
`安静进入 → 逐渐入流 → 中段小挫（一个长词/一个错键）→ 咬牙追回 → 结尾冲刺 → 结算爆发`

**基调**：深夜书房 + 一点点魔法。不喧闹、不幼稚、不 Q 版。参考气质：《Stardew Valley》的安静 +《Monument Valley》的克制 + 打字游戏该有的机械爽感。

**叙事克制原则**：全篇不超过 3000 字剧情文本，不做过场动画，不做对话系统。叙事只出现在：城区解锁的一句题记、卷轴完成的一句批注。**不要用剧情打断打字。**

## 2. 核心玩法：打字引擎

### 2.1 输入与判定规则

这是整个产品的物理层，必须一次做对。

| 规则 | 设计 | 理由 |
|---|---|---|
| 输入载体 | 隐藏 `<textarea>`（或 contenteditable）承接原生输入 + `keydown` 精确判定 | 兼容输入法关闭态、软键盘、无障碍 |
| 判定单位 | 单字符（char-level） | 需要逐字视觉反馈 |
| 错字处理 | 错误字符**原地变红 + 轻微抖动**，光标不前进 | 老式打字游戏会让光标卡住，非常挫败；不卡但显示错误，玩家能立刻自我修正 |
| 是否允许越过错字 | **不允许**。必须改对才能继续 | 防止"乱打冲速度"，保证每次击键都是真实的拼写输入 |
| 退格 | 允许，无限退格 | 打字是技能，允许纠错才有练习价值 |
| 准确率算法 | **首次正确率**（first-try accuracy）= 一次打对的字符数 / 总输入字符数 | 允许退格但准确率仍能反映真实水平，比"最终正确率"诚实得多 |
| 粘贴 | 禁用 + 检测到 Ctrl/Cmd+V 弹提示"记述者不用抄的" | 反作弊 + 保持仪式感 |
| 输入法 | 检测到 composition 事件 → 提示切换英文输入法 | 中文用户高频踩坑点，必须做 |
| 长按连发 | 检测 `event.repeat` 超过阈值 → 该字符不计分 | 反作弊 |
| 跳词 | 不支持（无 Tab 跳过） | 跳过 = 逃避生词，破坏学习闭环 |

**一个容易被忽略但要命的细节**：标点与大小写必须严格判定（`It's` 的撇号、`don't`、句首大写）。但**不做"智能引号"**（把 `'` 判成 `‘`），直接统一为 ASCII。同时在设置里提供"宽松模式"：忽略大小写（仅对 A1/A2 城区默认开启）。

### 2.2 节奏系统：连击 · 共鸣 · 断裂

打字游戏的"爽"来自节奏，不是来自分数。

- **连击（Combo）**：连续首次正确的字符数。屏幕左侧一条竖向光带随连击升高、变亮、边缘出现粒子。
- **共鸣（Resonance）**：每 30 连击触发一次。表现为：① 背景环境音多叠一层乐器（从单音钢琴 → 加弦乐 → 加人声哼鸣，共 5 层）；② 当前行文字外发光；③ 一次轻微的屏幕缩放（1.005）。**声音分层是本作最重要的爽感来源**，玩家会在 3 局内潜意识地把"连对"和"音乐变好听"绑定。
- **断裂（Break）**：打错一个字符，连击**不清零**，而是**掉一层共鸣**（最低回落到 0）。这是刻意的宽容设计——清零式惩罚会让玩家在第 40 连击时手抖，掉层则允许"修回来"。
- **完美卷轴（Perfect Scroll）**：全程无错字，结算时城市多亮一盏金灯（永久可见）。

**为什么用"掉层"而不是"清零"**：清零制造的是焦虑（怕失误），掉层制造的是挽回欲（想追回）。前者让人保守，后者让人上瘾。

### 2.3 幽灵竞速（Ghost）

每条卷轴在你完成后，会保存**这一次的击键时间轴**（每个字符的时间戳）。

- 下一次打同一条卷轴时，一个半透明的光点按旧时间轴前进，标着"昨天的你 · 62 WPM"。
- 超越时：光点碎裂 + 提示"已超越自己"。被反超时：提示"它在你前面 1.2 秒"，不嘲讽。
- 幽灵只保留**个人最佳**，且只在自己打过的卷轴上出现。
- v2 加入"好友幽灵"（云端回放，压缩到 2KB/条）。

**这是本作最强的沉迷钩子**：它把"变强"变成了一场看得见、追得上的比赛，且对手永远恰好比你强一点点——这是最理想的心流难度。

### 2.4 视口与滚动

- 可见 **3 行**，当前行居中偏上，上下行做 40% 不透明度渐隐。
- 滚动以**行为单位**（不是字符），整行上移 220ms `cubic-bezier(.2,.8,.2,1)`。
- 行宽限制 **62–70 字符**（约 68ch），字号 26–28px，行高 2.0。这是长时间阅读不疲劳的甜点区。
- 末尾 2 行显示为预览行，降低"不知道后面是什么"的焦虑。
- 光标：4px 竖条，琥珀色，带 1.6s 呼吸动画；打字瞬间高度轻微拉伸（弹簧）。

## 3. 学习系统（真正的差异化）

### 3.1 词汇掌握度模型

词表里每个词有一个 `mastery ∈ [0, 100]` 和一个 `stability ∈ [0, 5]`（记忆稳定度）。

| 事件 | mastery 变化 | 说明 |
|---|---|---|
| 首次打对（该词在本局第一次出现） | +12 | 主动产出，权重最高 |
| 打对（重复出现） | +4 | 边际递减 |
| 打错 | −6 | 惩罚温和，避免"越练越崩" |
| 点击查词 | `mastery = min(mastery, 25)` | 查词 = 承认不认识，必须把掌握度打回低值，否则推荐系统会误判 |
| 收藏进藏书阁 | 标记为 `learning`，进入复习队列 | |
| 复习答对 | +15，stability +1，间隔 ×2.2 | |
| 复习答错 | −20，stability −1，间隔归 1 天 | |

**词汇量展示**：`已掌握 = Σ(mastery ≥ 70 的词)`。这个数字直接对标"5000 词汇量"的目标，是玩家最在意的进度条。

**冷启动**：首次进入做 3 分钟的"水平探测"——3 条不同难度的短卷轴，由准确率 + WPM + 查词率反推初始词汇量（1000 / 2000 / 3500 / 5000 四档），避免新手被扔进 C1 文本。

### 3.2 i+1 选文：让"循序渐进"变成可计算的

这是"循序渐进"从口号变成机制的关键。

**每篇文本入库时计算 5 个静态特征**：

| 特征 | 算法 |
|---|---|
| 生词率 baseline | 文本中不在"核心 1000 词"内的词占比 |
| 平均句长 | 词数 / 句数 |
| 从句深度 | 依存句法树最大深度（spaCy） |
| 抽象度 | 抽象名词（-tion/-ment/-ity/-ness 后缀）+ 情态动词密度 |
| 综合难度 D | 加权映射到 1–7 档（A1.1 / A1.2 / A2 / B1 / B1+ / B2 / C1） |

**推荐打分（每条卷轴每次刷新时计算）**：

```
score = 0.40 × 目标生词率匹配(生词率 target = 6%)
      + 0.25 × 难度档与玩家能力匹配(玩家能力由近 5 局准确率+WPM 推算)
      + 0.15 × 到期复习词覆盖率(这条文本能触发多少待复习词)
      + 0.10 × 主题新鲜度(最近 10 局没碰过的主题)
      + 0.10 × 随机扰动(探索)
      − 惩罚(近 3 局打过的文本/同源文本)
```

- **生词率 6% 是理论甜点**：低于 3% 太简单会无聊，高于 10% 会挫败。设 3%–8% 为健康区，UI 上用"生词 n 个"标签直接告诉玩家。这让"选哪篇"从玄学变成有依据的决策。
- **难度自适应**：连续 3 局准确率 > 97% 且 WPM 上升 → 自动升半档；连续 2 局准确率 < 90% → 降半档，并提示"换一条轻松的"。**永远不让玩家卡在打不过的文本上。**

### 3.3 查词与语音（用户明确要求的核心功能）

**交互**：悬停 300ms 出轻量提示（音标 + 中文一行）；点击（或 `Tab` 聚焦）出完整卡片。

**词卡内容**（数据全部来自本地词库，0 网络延迟）：

```
┌─────────────────────────────────────────┐
│  resilience            /rɪˈzɪliəns/  🔊 │
│  n. 韧性；复原力；弹性                     │
│  ─────────────────────────────────────  │
│  英文释义：the ability to recover quickly │
│  from difficulties                        │
│  ─────────────────────────────────────  │
│  词形：resilient (adj.) / resiliently     │
│  频段：Tier 4 · CET6 · 柯林斯 ★★★☆☆      │
│  ─────────────────────────────────────  │
│  [ 收藏到藏书阁 ]      [ 听整句 ]  [ 关闭 ] │
└─────────────────────────────────────────┘
```

**三条体验红线**：

1. **查词不罚时。** 计时器在卡片打开时暂停，关闭后恢复。查词的心理成本必须接近 0，否则玩家会硬猜而不查——那就白做了。
2. **发音必须"秒响"。** 单词音频全部预烘焙成本地文件（约 6000 个 mp3/opus，单条约 8–15KB），点击到出声 < 50ms。**绝不允许点击后等 500ms 才响**，那会直接杀死使用意愿。
3. **不打断打字焦点。** 卡片关闭后光标回到原位，不需要再点一次输入区。

**语音能力分级**：

| 能力 | 实现 | 优先级 |
|---|---|---|
| 单词发音（美音/英音） | 预烘焙音频（edge-tts / Piper 离线生成） | P0 |
| 整句朗读 | 预烘焙句级音频 或 Web Speech API | P1 |
| 全文朗读（进入前预览） | Web Speech API | P2 |
| 慢速播放（0.7×） | 音频元素 `playbackRate` | P1 |
| 听写模式（只听不看） | 用于夜巡复习 | P1 |

### 3.4 夜巡复习（SRS，但用打字作答）

每天结束时（或随时）进入"夜巡"：只做**到期**的 8–15 个词，预计 90 秒。

**三种题型轮换**（同一批词，根据 stability 决定题型）：

1. **看中文打英文**（stability ≥ 2）：给 `韧性；复原力` → 敲 `resilience`。
2. **听音写词**（stability 1–2）：只播发音 → 敲出单词。空格直接判对错。
3. **句中填空**（stability 0–1，新词）：给一句含该词的句子，该词挖空 → 敲出来。上下文辅助编码。

- 答对：词卡飞出，城市某个角落亮一下。
- 答错：立刻展示正确拼写 + 发音，2 秒后重打一次。**不评价、不扣分、不显示"你错了"的红色大字**，只说"再敲一次"。
- **间隔序列**：1 → 3 → 7 → 16 → 35 → 75 天（FSRS-lite 简化版，实现成本低，效果接近 SM-2）。

**为什么复习不能是选择题**：选择题测的是再认（recognition），打字测的是提取 + 拼写（recall + production）。后者才是"会用"。

### 3.5 打字体检（弱项训练）

每周生成一份"手部报告"（免费，不做付费点）：

- **错误键热力图**（QWERTY 键盘图，按错误率着色）。
- **慢速组合**：统计 digraph / trigraph 的中位延迟，找出你的 `ough`、`th`、`-ing`、`x` 这类痛点。
- **自动生成 30 秒微练**：从词库里抽 20 个含该组合的词，组成一条"练习卷轴"。
- 这是纯工程价值的功能，但玩家会非常买账——因为它**只对你有用**。

## 4. 进程、留存与经济

### 4.1 七城区（难度即地图）

| 城区 | 难度 | 词汇目标 | 文本特征 | 解锁条件 |
|---|---|---|---|---|
| 1. 石阶巷 | A1.1 | 高频 800 词 | 5–8 词短句，寓言/日常 | 初始 |
| 2. 灯火市集 | A1.2 | 1200 词 | 简单叙事 | 完成 8 条卷轴 |
| 3. 钟楼区 | A2 | 2000 词 | 儿童文学、科普短篇 | 城区 2 星级达标 |
| 4. 雾港 | B1 | 3000 词 | 新闻、游记 | 城区 3 达标 |
| 5. 档案馆 | B1+ | 4000 词 | 说明文、传记 | 城区 4 达标 |
| 6. 星图台 | B2 | 5000+ 词 | 评论、社科 | 城区 5 达标 |
| 7. 无名塔 | C1 | 8000+ | 文学、学术随笔 | 城区 6 达标 |

每城区：12–20 条普通卷轴 + 1 条**守卫卷轴**（长文 400–600 词，限时，无退格"封印"模式，可放弃）。

- 守卫战失败不惩罚，只提示"再练 3 条卷轴回来"。
- 每城区完成 → 城市地图上该区域**永久点亮**，并解锁一句题记。

### 4.2 星级与奖励

单条卷轴结算按 **WPM × 准确率** 双轴给星：

| 星 | 条件 |
|---|---|
| ★ | 完成即可 |
| ★★ | 准确率 ≥ 95% |
| ★★★ | 准确率 ≥ 98% 且 WPM ≥ 该档目标值 |

- 奖励：星 → 城市亮度（可视化）、"墨"（软货币）→ 解锁卷轴皮肤/音色包（纯装饰，不做数值付费）。
- **不做体力系统**。想打多久打多久——这是一个练习工具，卡体力会激怒目标用户。

### 4.3 留存装置（分层设计）

| 层级 | 装置 | 作用 |
|---|---|---|
| 分钟级 | 连击共鸣、幽灵竞速、下一行预览 | 让"再打一条"的成本极低 |
| 日级 | 每日卷轴（全球同一条，3 次机会，日榜）、连胜火苗 | 制造回来的理由 |
| 周级 | 打字体检报告、周挑战（限主题） | 给"长期进步"可见的证据 |
| 月级 | 赛季（8 周）、段位（青铜抄写员 → 星辉记述者）、城市全亮 | 长线目标 |

**D1 手段**：首次会话必须让玩家在 6 分钟内点亮第一片街区（即时成就）。
**D7 手段**：连胜 + 每日卷轴 + 幽灵被超越的通知（"昨天的你在 1 号卷轴跑出了 71 WPM"）。
**D30 手段**：词汇量数字的持续增长 + 赛季段位。

**每日卷轴设计要点**：全球同一条文本，人人可比。3 次机会取最好成绩，用完就只能看榜。这是最低成本的社交，且不需要实时对战。

> **实现偏差（2026-11-01）**：当前版本没有后端，做成「本地确定性」——按本地日期哈希 +
> 当前城区抽一篇，当天固定、刷新不变；成绩取当天最好，不限制次数。
> 理由：没有日榜时，「全球同一条」拿不到可比性收益，而固定难度能保证新手第一天不会抽到 C1；
> 限制 3 次在无排行的情况下只会让人扫兴。接服务端后应改为固定池 + 次数上限 + 日榜。

## 5. 数据方案（1000+ 文章 · 5000+ 词汇）

> 全部使用可商用/开源授权，逐条标注来源与许可，成品页脚提供"数据来源"页。

### 5.1 文本来源

| 来源 | 许可 | 预估产出 | 难度 | 用途 |
|---|---|---|---|---|
| **Project Gutenberg**（儿童/青少年经典：Aesop's Fables、Alice in Wonderland、Peter Pan、The Secret Garden、Treasure Island、Black Beauty 等 8–10 本） | Public Domain | 700–900 段（每段 90–160 词，按段落/场景切分） | A2–B2 | 主线叙事内容 |
| **Simple English Wikipedia**（精选 600 篇：历史/科学/地理/人物） | CC BY-SA 3.0 | 1000–1400 段 | A2–B1 | 科普与说明文，词汇天然简单 |
| **Wikinews**（英文版，2020–2025 归档） | CC BY 2.5 | 200–300 段 | B1–B2 | 新闻体 |
| **Tatoeba**（英文句子，配中文翻译的句对） | CC BY 2.0 FR | 3000+ 句 | A1–B1 | 句中填空、夜巡素材、回声微练 |
| **LibriVox**（PD 有声书） | Public Domain | 音频 | — | 可选：真实人声朗读（v2） |
| **LLM 分级改写**（仅对 PD 文本改写，规避衍生版权） | 自有 | 300–500 段 | 精确控档 A1.1–C1 | 补齐低难度与高难度两端的缺口 |

**产出配比目标**：A1.x 25% / A2 25% / B1 25% / B2 18% / C1 7%，合计 **≥ 1200 条**，超过"1000+"要求并留出淘汰余量。

### 5.2 词典底座：ECDICT（MIT）

`skywind3000/ECDICT`，开源英汉词典（CSV / SQLite 双格式，约 77 万基础词条，完整版 222 万）。

关键字段正好覆盖本作全部需求：

| 字段 | 用途 |
|---|---|
| `word` / `phonetic` | 词头 + 音标（词卡第一行） |
| `translation` | 中文释义（多义项换行分隔） |
| `definition` | 英文释义（词卡第二段） |
| `collins` / `oxford` | 柯林斯星级 / 牛津 3000 标记 → 词卡"重要度" |
| `tag` | `zk/gk/cet4/cet6/ky/ielts/toefl/gre` → 直接对应中文用户的考试标签，**这是最打动目标用户的一栏** |
| `bnc` / `frq` | 双词频排名 → 分档 Tier 1–5、稀有度 |
| `exchange` | 词形变化（时态/复数/比较级/lemma）→ 词卡"词形"与**词形归一化**（打 `running` 应记到 `run` 头上） |
| `pos` | 词性频率 → 决定词卡首行显示哪个词性 |

许可：MIT，可商用。需保留版权声明。

### 5.3 词表分层（5000+ 核心词）

1. **合并排序**：`ECDICT.frq`（当代语料）+ `wordfreq` 库（MIT，更贴近现代用法）取加权排名，避免单一语料的时代偏差。
2. **交叉校验**：与 **NGSL**（New General Service List，CC BY-SA 4.0，2809 词，覆盖一般文本 ~92%）取并集，确保高频词不漏。
3. **切 5 档**：

| Tier | 词频区间 | 词数 | 对应城区 |
|---|---|---|---|
| T1 | 1–1000 | 1000 | 1–2 |
| T2 | 1001–2000 | 1000 | 3 |
| T3 | 2001–3000 | 1000 | 4 |
| T4 | 3001–4000 | 1000 | 5 |
| T5 | 4001–6000 | 2000 | 6–7 |

合计 **6000 词**（超出 5000 要求，留冗余），并保留扩展到 2 万词的机制（后续 Tier 6–8）。

4. **词形归一**：用 `exchange` 字段 + lemma 库把 `went → go`、`children → child`、`better → good` 归到同一个掌握度上，否则玩家会"重复学 5 遍同一个词"。
5. **多词短语**（`look forward to`、`as a result`）单独建表，标注 `phrase: true`，因为真实文本里它们出现频率极高。

### 5.4 音频烘焙（离线预生成，是体验底线）

| 项 | 方案 |
|---|---|
| 引擎 | `edge-tts`（神经语音，质量高）离线批量生成；备选 `Piper`（MIT，纯本地） |
| 音色 | 美音 `en-US-AriaNeural`、英音 `en-GB-SoniaNeural` 各一套，设置里可切 |
| 覆盖 | 6000 核心词 + 3000 多词短语 + 1200 条文本的句级音频（可选） |
| 格式 | `opus` 32kbps 单声道，单词约 6–10KB，总量约 **80MB**；按 Tier 分 5 个包，懒加载 |
| 文件名 | `audio/w/{sha1(word)}.opus`，前缀分桶（`w/ab/…`）避免单目录 6000 文件 |
| 兜底 | 音频缺失 → 回落到 Web Speech API（`SpeechSynthesisUtterance`，rate 0.9） |

### 5.5 数据流水线（离线脚本，产物为静态 JSON）

```
[抓取] → [清洗] → [切分] → [标注] → [打包]
   │         │        │         │        │
 Gutenberg 去头尾   90–160词  spaCy   articles/
 SimpleWiki 去wiki标记 段落   词性/依存  index.json
 Wikinews  去模板   句对齐   生词率    audio/
 Tatoeba   去噪声            CEFR估算  dict.sqlite → dict.idx
                             敏感词过滤
```

- **敏感内容过滤**：Gutenberg 老文本含种族/暴力内容，需人工+LLM 双过滤（尤其儿童文学中的时代偏见）。
- **产物体积预算**：文本 JSON 全量约 2–3MB（gzip 后 < 900KB）；词典按 Tier 分片，每片 200–400KB；首次加载只拉 T1。
- **可复现**：所有脚本入 `scripts/`，附 `LICENSE-NOTICE.md` 逐源声明。

## 8. 阅读填空（2026-11-01 增补）

**定位**：介于「打字」与「夜巡」之间的第三种练习。
打字考的是**产出手速**（照抄），夜巡考的是**脱离上下文的词汇回忆**，
填空考的是**在上下文里补全**——搭配、时态、介词、以及"这个位置该是什么词性"。这三件事互不替代。

### 8.1 出题算法

从既有文章挖空，不新增任何数据。规则按重要性排序：

| 规则 | 理由 |
|---|---|
| 优先掌握度 20–70 的词 | 太生填不出来只会挫败，太熟填了没收获 |
| 高频词里只排除虚词 | 入门文章几乎全是 Tier 1；若统一要求 Tier ≥ 2，L1 会挖不出空 |
| 跳过专名 | `Matthew` 挖空只能靠背原文 |
| 空距 ≥ 22–45 字符（按文长自适应） | 两个空挨太近，整句失去可推断性 |
| 每句按长度分配 1–6 个空 | 831 字符的单句长文需要更多空，否则练不起来 |
| 句首词不挖 | 它是句子的骨架，缺了整句读不通 |

**确定性**：以 `seed:文章id` 做 FNV 哈希排序，同一篇每次挖同样的空——否则"换一篇再回来"会换题，没法比较。

### 8.2 数据体检结论

`npm run audit:cloze` 对 1156 篇各生成一次：

- 平均 **6.0 空/篇**，L1 5.4 → L6 6.2
- 挖到专名 **0**、缺中文提示 **0**、重复挖同一位置 **0**、空距过近 **0**
- 有 **3 篇（0.26%）** 挖不出 4 个空（几乎全是虚词，内容词又缺词条）→ **选题时自动跳过**，
  不放宽算法硬凑无意义的空

### 8.3 提示三档与掌握度闭环

提示：`无 / 首字母 / 首字母+释义`，写在 settings 里（默认首字母）。

判定与夜巡共用同一套掌握度：填对 `+12`，填错 `-8` 且 `er+1`、`due=当天`——
也就是说**填错的词当晚就会进夜巡**，两种练习自动咬合，不需要额外的调度逻辑。

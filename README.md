# 词醒 · TypeWake

> 一座文字沉睡的城市，你是记述者。打字 = 唤醒。你敲下的每一个词，都会变成你真正拥有的词。

英文打字训练游戏。**1179 篇分级英文文本**、**7584 词词典**、点词即查即听、连击共鸣、幽灵竞速、夜巡复习。

## 快速开始

```bash
npm install
npm run dev            # 浏览器 http://localhost:5183
npm run tauri:dev      # 桌面端开发模式（自动起 vite）
npm run tauri:build    # 打包安装程序（nsis / msi）
```

> 想直接跑现成的可执行文件：**[`release/TypeWake-0.1.0-win-x64.exe`](release/TypeWake-0.1.0-win-x64.exe)**
> （4.6 MB，单文件，已内嵌全部文本与词库，双击即可，不需要装 Node 或 Rust）。
> 这是某次构建的快照；代码更新后跑 `npm run exe` 重新构建。
>
> 注意：**必须用 `npm run exe`（内部走 `tauri build --no-bundle`）**，
> 直接 `cargo build --release` 编出来的是 dev 壳 —— 它去连 `localhost:5183`，
> 本机开着 vite 时看着正常，换台电脑就是一片空白。

桌面端首次启动会在 `%APPDATA%\com.typewake.app\` 生成 `ready.json`，
内容形如 `{"articles":1179,"words":7584}`。它由 Rust 侧在启动时写入，
**只能说明后端读到了数据，不能说明界面渲染出来了** —— 白屏时这个文件照样会生成。
判断界面是否正常，看窗口里有没有出现侧边栏和「今日卷轴」。

**数据存哪里**：默认 `%APPDATA%\com.typewake.app\`，三个文件 ——

| 文件 | 内容 |
|---|---|
| `progress.json` | 全部学习进度（词表 / FSRS 排期 / 场景成绩 / 自建对话），十几 KB |
| `runs.jsonl` | 每次结算的一行记录 |
| `ready.json` | 启动自检标记 |

**可以换位置**：设置 → 数据目录 → 更换目录，挑一个文件夹（比如同步盘或移动硬盘）。
更换时只**复制**不删除，旧文件留着；指向记在默认目录的 `config.json` 里。
自定义目录不可用时会自动回落到默认位置，不会在本机凭空造一棵新目录。

首次运行需要数据。仓库已包含构建产物（`public/data/`），如需重新生成：

```bash
npm run data         # 下载公版书 + 维基百科，重建 1179 篇文本与 7200 词词库（约 2 分钟）
npm run data:dict    # 把对话语料的 384 条补充词条并进词库（幂等，可反复跑）
npm run icons        # 从 design/icon.svg 重新生成全平台图标
npm run translate    # 补齐句子译文（已完成全量；改语料时才需要重跑）
npm run names        # 重新统计专名表 public/data/names.json（改语料后需重跑）
npm test             # 一键全量校验：结构 + 内容 + 界面 + 语音（改代码或数据后都跑这个）
npm run test:data    # 只跑数据层（结构 + 质检）
npm run test:daily   # 只跑每日卷轴（确定性 / 连续 / 预告）
npm run test:report  # 只跑体检报告（统计与诊断）
npm run test:cloze   # 只跑阅读填空（出题 / 判定 / 回写）
npm run audit:cloze  # 对 1179 篇全量生成填空，检查不变量
npm run verify       # 只校验译文与句数对齐、无空句
```

## 技术栈

| 层 | 选型 |
|---|---|
| 前端 | React 18 + TypeScript + Vite + Zustand |
| 打字引擎 | 自研纯 TS，逐键直改 DOM，不触发 React 重渲染 |
| 桌面端 | Tauri 2（Rust 1.77+），WebView2 |
| 数据 | 静态 JSON 分片，全量本地化，断网可玩 |

| 语音 | Web Speech API，本地零延迟 |

## 玩法

1. **打字** —— 逐字符判定，错字原地变红但不位移，必须改对才能继续。
2. **连击段位** —— 30 / 60 / 100 连击分别进入「顺流 / 共鸣 / 无我」：
   音高递进、左侧光带变亮变粗、右上角数字转暖，升段的一刻舞台上方亮一下名字。
   打错只掉 30 连击，不清零。
3. **错字护盾** —— 每 50 连击攒一颗（上限 2）。打错时自动顶掉一颗、连击不断。
   攒满两颗等于给自己两次冒险的本钱 —— 连击从「只会掉」变成「能攒出东西」，
   50 之后人才会真的开始屏住呼吸。护盾用尽后再错才掉连击。
4. **句末结算** —— 每打完一句，右下角浮一行：第几句、用了几秒、是否零错（零错标「完美」）。
   一篇文章从三分钟的长镜头，变成每几秒一个反馈点。
5. **查词** —— 点任意词出卡片，计时暂停；发音 <50ms。查过的词掌握度会被打回 25（承认不认识）。
6. **幽灵** —— 每条卷轴保存你最好一次的击键时间轴，下次一个光点按旧轨迹跑（设置里默认关）。
7. **推进** —— 文本按你的生词率推荐（目标 6%），7 个城区 A1.1 → C1，连续 8 条解锁下一区。
8. **夜巡** —— 到期词用打字作答：看中文打英文 / 听音写词 / 看英文释义打词。
   队列里还会夹一两句**到期的句型**（看中文打整句）—— 复习只有一个入口，不用记两套节奏。
9. **每日卷轴** —— 每天固定**一篇文章 + 一场对话**（按日期确定性抽取，当天不变），
   完成任意一项即累积「每日连续」，两项都做是 2/2；文章那项记录今日最好成绩并预告明天。
   对话那行点进去直接打开那一场，不用回列表找。
10. **阅读填空** —— 从文章里挖空（优先半熟词、避开专名、控制间距），在上下文里补全；
    提示三档（无 / 首字母 / 首字母+释义），完整提示档带焦点随动的整句中文译文；
    填错的词当晚自动进夜巡。
11. **结算** —— 星级 + WPM + 准确率 + 「完美 N/M 句」+ **下一步目标**
    （「再快 3 WPM、准度再提 2 个点，就是三颗星」）。不给「继续加油」，只给具体动作。
12. **体检报告** —— 一句话诊断（准确率 / 节奏 / 手速哪个是瓶颈）+ WPM 趋势 + 易错键对 + 反复打错的词 + 练习建议。
    练过对话会多出一块「说台词 vs 实战接住」——两种能力的差距能看出你是背得熟还是真能接；
    下面再按岔路类型拆（东西没了 / 要加钱 / 流程变了 / 被追问 / 对方提议），
    指出你最容易卡在哪一种意外上。
13. **文库** —— 1179 篇全部摊开，按来源分组、书内按原文顺序，标段号与已读星级；
    支持搜书名、按城区筛选。城市页只推荐一篇，文库才看得到全库。
14. **阅读** —— 文库点一篇先进阅读页，不是直接开打：完整全文、按句排版，
    **中文译文贴在对应英文句子的下方**（可一键切回原文），生词带点状下划线、点词即查，
    点句子听读音；读完再按「开始打字」，退出会回到这一页，不会把人扔回地图。
    可以「上一段 / 下一段」顺着一本书往下读。
11. **预习卡** —— 进正文前把本篇生词先考一遍：只给中文释义和首字母，要你回忆出英文，
    答错立刻亮答案。先测后学（pretesting effect），即使答错也能提高后续的记忆强度。
12. **记忆调度（FSRS）** —— 每个词有自己的难度与稳定度，间隔按遗忘曲线算，不再共用一张固定阶梯。
    词卡里能看到「记忆：3 周后复习 · 难度 5/10」。
13. **场景对话** —— 按「情境骨架 × 变体」生成：一段对话一个骨架，同一情境的不同走法（赶时间 / 带娃 / 只有现金 / 东西卖完了）各算一场。
    当前 204 个情境 / 1157 场，9500 句手写台词，每场至少一处岔路。
    十五类：日常 / 餐饮 / 购物 / 出行 / 职场 / 医疗 / 社交 / 学习 / 服务 / 政务 / 租房 / 生活 / 财务 / 家庭 / 住宿。
    **入门（L1）85 场**另写一批：一句 4–8 词、只用最常用的词，第一次开口就能用
    （打招呼 / 道谢 / 道歉 / 问价 / 问路 / 问几点 / 要点喝的 / 带走还是堂食 / 买票 / 寄信）。
    语料源在 `scripts/dlg/*.mjs`，`npm run data:dialogues` 生成 `public/data/dialogues.json`。
    列表按难度升序分组；搜索按相关度排序（情境名 > 描述 > 台词原文），命中台词时卡片会引一句出来，
    再加进度（未练 / 已练 / 待重温）、类别、难度、收藏四类筛选；练过但超过 14 天没再练的标为「待重温」，
    按最久没练的排前面。首页也会冒一行「该重温 · 对话」，点进去直接落在筛好的列表。
    卡片可收藏（★），场景内可「上一场 / 下一场」直接接着练，
    页头按钮「随机一场」优先给没练过的。`npm run audit:dialogue` 做语料体检（重复句 / 难度失真 / 岔路覆盖）。
    四种练法：**通读**（气泡 + 连播）→ **跟打**（照打你的台词）→ **背打**（只看中文回忆英文）
    → **跟读**（对着麦克风说，逐词判对）→ **实战**（对方中途不按剧本说话，只给目标不给答案）。
    可以**导入自己的对话**（一行一句 `角色: 英文 | 中文`），课本材料、自己写的台词都能用同一套练法；
    想加「对方突然改口」就补两行 `? 目标 | 对方的话` 和 `+ 你的应对 > 对方的反应`。
    练完一场，那场的**句型**会进句型复习池（看中文打整句，走同一套 FSRS），入口在对话列表顶部；
    到期之后也会混进夜巡。
    每种练法都能**换角**（练对方的话轮），
    两个角色的成绩分开记，卡片打 `✓✓` 才算这场对话真正走通。
    判分不计较标点大小写，但错一个字母就算错；打错的词当晚进夜巡。
    跟读用浏览器自带的语音识别，桌面端不支持时自动降级为跟打。

## 数据与备份

所有学习记录只存在浏览器的一个 `localStorage` 键里（`typewake:v1`）：词的掌握度与 FSRS 排期、
打字成绩、场景对话成绩、句型复习进度、自建对话。**清一次站点数据就全没了，换台机器也带不走。**

设置 → 数据 → 进度备份，可以把整份档案导出成一个 JSON（文件名 `typewake-YYYY-MM-DD.json`），
或从备份里恢复。导入是**覆盖**，确认框会把「当前」和「备份」两边的数字并排摆出来再让你点。

宽进严出：没有版本号、没有应用标记的老文件也照收（给一条提醒），
真正拒收的只有「解析不了」「不是本应用的档案」「里面没有学习数据」三种，且说清是哪一种。

```json
{ "app": "typewake", "v": 1, "at": "2026-11-02T07:00:00.000Z", "p": { … }, "s": { … } }
```

## 已知边界

- 移动端仅保证复习与浏览体验，打字为主桌面端设计。
- **进度只在本地**：没有账号、没有服务端，换设备靠导出的 JSON 手动搬。
- 语音走系统 TTS，音色取决于操作系统；生产环境应预烘焙单词音频（见设计文档 §5.4）。
- **句子译文已全量覆盖**：**1179 / 1179 篇（100%）**，七个城区，共 **5446 句**（`tr.json` 0.55 MB）。
  若改动语料需要重译：`scripts/next-batch.mjs` 导出批次 → 逐句翻译 →
  `scripts/import-tr.mjs <批次文件>` 合并（**会比对句数，不符直接拒收**）。
- **专名表**：`scripts/build-names.mjs` 从语料统计人名地名（192 个，1.7 KB），
  句子解析里跳过，避免把 `Matthew` 注成「马太福音」。改语料后需 `npm run names` 重跑。
- **每日卷轴**已实现（文章 + 对话各一项），但只做了「本地确定性」这一半：
  按本地日期 + 当前城区抽一篇，当天固定。
  设计文档里写的「全球同一条 + 3 次机会 + 日榜」需要服务端才能成立，暂缓（无后端时限制次数
  只会让人扫兴，而拿不到任何可比性收益）。
- 排行榜在设计文档中，尚未实现（需要服务端）。
